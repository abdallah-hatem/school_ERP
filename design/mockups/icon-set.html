Custom icon set — precise monoline, solid when selected

Every icon the app uses, drawn on one 24-point grid: 1.5 line, round ends and joins, 2.5 corner radius, 2 points of padding. Outline everywhere; the selected sidebar item, tab or toggle switches to the solid version of the same shape (inner details are cut out, so it works on any background). Single colour — currentColor, shown here in deep teal.

Review only — not wired into the app yet. Sources: design/icons/outline/*.svg and design/icons/solid/*.svg.
