# Business logic — index

What is true **now** about the business and how the system behaves. Business terms only. Each section
is its own file; "§N" means the file listed for N below. Dated changes go in
[`business/00-recent-changes.md`](business/00-recent-changes.md).

## Markers

- **DECIDED** — confirmed by the owner or the client's documents.
- **GUESS** — our default where the client's documents are silent; shown to the client to confirm.
- **OPEN** — not decided; the system does not depend on it yet.
- **Planned** — agreed for later, not built.
