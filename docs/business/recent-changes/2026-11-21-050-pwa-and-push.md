# 2026-11-21 — The ERP installs as an app, and sends alerts to phones and computers

**Install it.** The ERP can be installed like an app on a phone, tablet or computer: it opens in
its own window from the home screen or dock. The app is named after the school and its icon is the
school's logo from Settings → School (a generic icon until a logo is uploaded). A new logo changes
the icon for everyone; nothing about a school is built into the app.

- On Chrome, Edge and Android, **My account → Install app** opens the browser's own install dialog.
  On an iPhone or iPad, it shows the three steps (Share → Add to Home Screen → open it from there).
  Where the browser can't install, nothing is shown. No banner ever asks.
- Without a connection, a page shows a short "You're offline" page with the school's name and a
  Try again button, and opens by itself when the connection is back. Pages and data are never
  kept on the device: everything is per person (§2).

**Alerts on this device.** Everything that reaches the bell (§11) can also arrive as an alert on the
person's phone or computer, even with the app closed.

- **My account → Notifications → Alerts on this device**: one switch for the device in hand. Turning
  it on asks the browser's permission; the first alert confirms it. Under it, **My devices** lists
  every device that gets the person's alerts ("Chrome on Android", when added, the last alert),
  each with Remove. Signing out turns the device's alerts off (a shared computer keeps nobody's).
- Alerts follow the person's choices per kind of notification (the switches below it); the kinds
  that can't be turned off (approvals) always come. Nothing new in Settings → Notifications.
- An alert says what the bell says, in the device's language, and opens the same page. It never
  shows money (no payroll net) or a typed reason — those stay in the app.
- When the switch can't be used, it says why: alerts blocked for the site in the browser, an old
  browser, an iPhone where the app isn't on the Home Screen yet, or the server not set up for alerts.
- Adding and removing a device are recorded in the Activity log (they decide where the school's
  notifications show). Reading notifications still isn't.

**Limits.** Installing and alerts need the app on **https** (or `localhost` for a developer).
On iPhone and iPad, alerts work only **after Add to Home Screen**, on iOS / iPadOS **16.4 or later**.
A device that is off gets its alerts when it comes back, for up to a day.
