# 2026-11-18 — Probation end on the employee record

Each employee now has a **probation end** date (§3, owner). Left empty when adding an employee, it
is filled with the hire date plus the school's **default probation length** — a new HR rule in
Settings → HR rules → Employees, **3 months** by default (0 to 6; 0 = no probation, the date stays
empty) — the day before: hired 1 September → 30 November. It can be changed or cleared on the
employee form ("Probation ends", under the hire date), never before the hire date. Changing the hire
date doesn't move it; changing the default length only affects employees added afterwards. It shows
on the profile to whoever sees the employee (it isn't salary data). Edits to it are in the employee's
history. Every existing employee was given hire date + 3 months. The probation reminder (§11) will
use it.
