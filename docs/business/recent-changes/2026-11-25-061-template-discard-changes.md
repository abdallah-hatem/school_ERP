# 2026-11-25 — Contract template editor: Discard changes

The owner: a way to restore the template when something was edited by mistake, without leaving the
page and starting again, pressable only when something changed.

- **Template editor (§3 → Contract templates):** a **Discard changes** button beside Save. It is
  enabled only while the names, the "Default for" choice or either text differ from the last saved
  version (typing and deleting back counts as no change). It asks first; confirmed, everything goes
  back to the last saved version — a new template to empty — the undo history is cleared, and the
  language tab stays where it was.
- **Nothing is sent or recorded:** discarding only throws away what is on screen.
