# T20 — UI audit fixes (class ui)

Branch `feature/t20-audit-fixes`, based on `origin/dev` 240aef3.

## Items
1. **Blocker, date picker month/year menus**: the calendar nav is `pointer-events-none` (its buttons `pointer-events-auto`). Covered by Playwright `07-date-picker` (mouse, EN + AR) and `08-date-picker-phone` (tap, AR phone).
2. **Arabic dates**: dropped `dir="ltr"` from the date `<bdi>`s (penalties table, profile, runs list, payslip). The date-field trigger had none. Component test: Arabic date not under an LTR direction.
3. **Change history**: columns wrap (`whitespace-normal`), widths are constrained, and it becomes cards below a 900px container (new `cardsBelow={900}`). The shared table draws edge fades only on a side that actually hides columns (`useScrollEdges`).
4. **Pagination on phones**: below 768px it shows previous / "Page X of Y" / next only (new key `ui.table.pageOf`).
5. **Payslip on phones**: stacked penalty entries below `sm`; the table stays from `sm` up and in print.
6. **Chevrons**: react-day-picker's orientation maps to a physical icon by direction, so "previous" points to the start edge.
7. **Selects**: a Radix `DirectionProvider` in `I18nProvider` makes every Radix primitive follow the page direction (Select had forced `dir="ltr"`). Options wrap (`whitespace-normal wrap-anywhere`).
8. **Approve with pending penalties**: a notice on the draft run page (from the lines' `PENDING_PENALTIES` flags) with a link to `/penalties?month&status=PENDING`. The button stays enabled and the 409 handling is unchanged. New prop `penaltiesHref`.
9. **Violation list width**: Select content is as wide as its trigger (calendar menus excepted).
10. **Edit-violation dialog**: a short title, "Edit violation", with the name below clamped to 2 lines. Every `nameAr` input already had `dir="rtl"`; a test now covers it.
11. **Mixed scripts**: new `BidiText` isolates the other-language name, notes, history values, cancel reasons and adjustment reasons.
12. **Switch off state**: `bg-muted-foreground/70`.
13. **Phone top bar**: the school name can take 2 lines (`line-clamp-2`).
14. **Lateness invalid minutes**: an error icon beside the input opens the message. The message is also the input's description for screen readers, and the row height stays the same.

**Seed**: the cancel reason, adjustment reasons, the penalty note and the default cancel reason are now Arabic. `seed-data.local/` holds none of these, so it is unchanged.

## Doubts
- The pending-penalties notice counts the run lines on screen. With a search or department filter active, those lines are filtered, so the notice can be missing. The server's 409 still blocks the approval.
