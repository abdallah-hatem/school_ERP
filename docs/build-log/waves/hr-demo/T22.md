# T22 — Employees as cards + module sidebar, option B (class ui)

Branch `feature/t22-cards-sidebar`, based on `origin/dev` a59d957. Built from the owner's pick, option B of
`design/mockups/employees-cards-and-sidebar.html`.

## Sidebar grouped by module
- Module registry `NAV_MODULES` in `core/navigation/nav-items.ts`: `{ key, nameKey, icon, tone, items[], status: 'live' | 'soon' }`.
  Adding a module is one entry plus its name in `common.nav.modules`. Home (Dashboard) is drawn as one link,
  HR as a collapsible group with a coloured tile, Accounting / Inventory / Students locked with a "Soon" tag (not links, not focusable).
- Groups are open by default and whenever one of their pages is current; open/closed is remembered per group
  in `localStorage` (`nav.groups`, every access in try/catch, server renders open). A toggle wins on the current page.
- Settings and the signed-in user (name, role, sign-out) at the bottom. The dashboard layout now reads the session on the
  server (`getSession`) so the user chip is there at first paint.
- Tablet rail (768–1279px): one icon per module with tooltip; HR opens its pages in a flyout (Radix Popover, opens towards the content in both directions).
  Phone drawer: the same grouped menu.

## Employees as profile cards
- Card grid replaces the table: band coloured by stage (new tokens `--band-1…4`, `--band-neutral` for "None", `--band-inactive`),
  stage tag + code on the band, initials tile over it, name + job title, status pill, department and work system, basic salary band, View / Edit.
  3 per row from a 900px content area (1280px window), 2 from 620px, 1 below.
- 12 per page, fixed (`EMPLOYEES_PAGE_SIZE`; a `limit` in the URL is ignored, never written). No rows-per-page control.
- Search, four filters (a filter in use is tinted), result count, URL-synced state, empty / no-results / error states kept;
  a page or filter change dims the current cards. Loading skeleton = 12 card skeletons in the same frame and grid.

## Doubts
- Stages have no "no stage" flag, so the neutral band is chosen by the stage's English name being "None" (§3 DECIDED name). A school renaming it would get a coloured band.
- The mockup's sort indicator ("Sort: Code") is not built — the API sorts by code and there is no sort control.
