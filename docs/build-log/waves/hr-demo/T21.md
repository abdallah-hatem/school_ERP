# T21 — Dry-run fixes (class ui + one backend change)

Branch `feature/t21-dry-run-fixes`, based on `origin/dev` 42d4b0e.

## Items
1. **Live pending-penalties notice**: `GET /hr/payroll-runs/:id` (and every response that returns a run) now carries
   `pendingPenalties`. It is the current count of PENDING penalties dated in the run's month, read through
   `PenaltyRecordsService.pendingCountInMonth`, and it is 0 on an approved run. The draft run page uses it.
   When it is 0 but lines still carry `PENDING_PENALTIES` from the last calculation, an info hint reads
   "Penalties changed since the last calculation", with its own "Recalculate now" button. The 409 on approve is unchanged.
   This also fixes T20's doubt: the old notice counted filtered lines. Contract (spec table) and `PayrollRun` type updated.
   The notice body now counts penalties, not employees.
2. **Searchable employee picker**: new shared `Combobox` (Radix Popover + search box + listbox). It matches either
   name or the code and ignores case, accents, Arabic marks and hamza / ya / ta-marbuta variants. It supports arrows, Home / End
   and Enter, has 44px rows and follows the page direction. `ComboboxField` is its react-hook-form wrapper.
   `SelectOption.keywords` was added, and `employeeOptions` (active only) fills it with both names and the code.
3. **Arabic number agreement**: `formatDayCount(days, lang)` in `packages/shared` gives 1 → يوم واحد, 2 → يومان,
   3–10 → N أيام, 11+ → N يومًا, fractions → N يوم, with Western digits. English gives "1 day", "0.5 day", "2 days".
   It is used by `<Days>`, `describeAction` (new keys `penalties.action.deduct` / `investigation` replace the One/Many
   pairs), the lateness summary, the lateness rule in Arabic, the payslip lateness line, the settings example,
   the catalogue level chips and the change history.
4. **Sticky Save bar**: while its form has unsaved changes, `SaveBar` is `sticky` at the viewport bottom, above the
   safe area. It is sticky, not fixed, so it never covers the end of the form. In HR rules it moved from the last card
   to be a direct child of the form, so it follows the whole form. School settings use it the same way.
5. **Tab title**: the signed-in layout sets the template `"%s · <school name>"` in the current language
   (`titleTemplateFor`, product name as fallback). Each page sets its section name (`sectionMetadata`). Sign-in shows
   "Sign in · <school>".
6. **Run tiles on phones**: 2×2 from a 320px container, with Net first. `StatTile` is a size container, and the figure
   drops to `text-xl` in a tile narrower than 13rem. The dashboard is unchanged at its widths.

Smoke specs: 03 now types the code in the employee search. 05 clicks Recalculate with `exact` because the hint has its own button.
