# T3: Design system and app shell

Branch `feature/t3-design-shell` (from `d9ee427`). Class: frontend · ui. Date: 2026-11-17.

## What landed

- **Tokens** (`apps/web/src/app/globals.css`): the Campus palette from the mockup as CSS variables
  mapped to Tailwind (`@theme inline`) — surfaces, teal `primary` (+ `-soft`, `-hover`), sunflower
  `accent` (+ `-soft`), `success` / `warning` / `destructive` / `info` each with `-soft` and an AA
  `-ink` text shade, `border`, `input`, `ring`, `overlay`; radius scale; three shadows
  (`card`, `raised`, `primary`); `ease-snappy` / `ease-drawer` curves; `--z-popover`. **Light only.**
  Utilities: `tabular` (Latin tabular figures), `scrollbar-clean`, `flip-rtl`. Radix scroll-lock
  margin neutralised so overlays never shift the page.
- **Fonts** (`shared/lib/fonts.ts`, `next/font`): Plus Jakarta Sans (Latin + all figures, with an
  explicit Arabic fallback), IBM Plex Sans Arabic (Arabic body), Tajawal (Arabic headings).
- **Icons:** Phosphor duotone, wrapped once in `shared/components/ui/icons.tsx`.
- **Shell** (`app/[locale]/(dashboard)/layout.tsx` → `core/navigation/app-shell.tsx`): sidebar
  ≥1280px, icon rail 768–1279px, top bar + Radix-sheet drawer from the inline-start edge <768px;
  EN / ع switch (`shared/components/layout/locale-switch.tsx`) flips `lang`/`dir` at once, keeps
  path + query, client navigation with `scroll: false`, writes the `lang` cookie `apiFetch` reads.
  An `account` slot is left for T2's user card.
- **Navigation** (`core/navigation/nav-items.ts`): Dashboard, Employees, Penalties, Lateness,
  Payroll, Settings — all routes exist as placeholders (`ComingSoon`) under `(dashboard)/`.
  `app/[locale]/page.tsx` moved to `(dashboard)/page.tsx`.
- **Settings / branding** (`core/settings`): `GET_SCHOOL_SETTINGS` (`apis.ts`, tag
  `school-settings`, `ignore401Redirect`), `brandingFrom` falls back to the product name and the
  generic mark when the call fails (404 until T4, API down, signed out), `SchoolBrandingProvider` +
  `useSchoolBranding().setBranding` so T10 can update the shell immediately after a save.
- **Shared components** (see list below), client i18n (`I18nProvider` / `useTranslation`, nested
  providers merge a module's namespace), new `ui` locale namespace (en/ar, identical keys).
- **Formatters:** `formatMoney` / `parseMoney` / `formatDays` in `packages/shared` (pure, integer
  arithmetic), re-exported from `apps/web/src/shared/lib/format.ts` with `formatCount`,
  `formatDate`, `formatMonth`, `toIsoDate`, `fromIsoDate`.
- **docs/DESIGN.md:** feel, colour roles, type, layout, icons, motion, states, what to avoid
  (no hex values).
- **Dependencies added (web):** `@phosphor-icons/react`, `radix-ui`, `react-hook-form`, `zod`,
  `@hookform/resolvers`, `react-day-picker`, `date-fns`; dev: `@testing-library/user-event`,

## Doubts / notes

- **Forms must use `<Form>` (`noValidate`).** With `required` on inputs, the browser's own bubbles
  otherwise block submit before zod runs.
- **Currency position:** the label sits left of the figure in both languages (`EGP 14,000.00`,
  `14,000.00 ج.م`), in `<Money>`, `MoneyField` and `StatTile`. Arabic currency label is `ج.م`.
- **Logo URL:** rendered as given by `GET /settings/school` (`next/image`, `unoptimized`). If the API
  returns a path on the API host, the web app needs a `/files` rewrite or an absolute URL — T2/T4
  should settle which.
- `next dev` generates `apps/web/AGENTS.md` (Next 16 `agentRules`); not committed. Consider
  `agentRules: false` in `next.config.ts`.
- The `lang` cookie is written client-side by the switch; T2's middleware may want to read it to
  route `/` to the chosen language (currently `/` → `/ar`).
