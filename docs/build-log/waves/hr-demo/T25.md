# T25 — Searchable pickers, row ⋯ menus, add badge (class ui)

Branch `feature/t25-pickers-row-actions`, based on `origin/dev` da1c599, rebased over T24 (#36).

## Items
1. **Pickers above 6 options search.** `SelectField` and `FilterSelect` switch to the shared `Combobox`
   by themselves when the list can hold more than 6 options (`SEARCH_THRESHOLD`, grouped options and
   the filter's "All" counted); `searchable` forces either way. `ComboboxField` is gone (one component).
   `Combobox` gained `groups`: headings stay while filtering, a group with no match hides.
   - Forced on (record lists that outgrow the seed): employee and violation pickers (record penalty),
     stage / department / job title / manager (employee form), department and stage filters (employees
     list), department filter (payroll run). Options carry keywords (both names, the code).
   - Automatic: the work start / end dropdowns (31 half-hour steps). Plain (≤ 6): gender, work system,
     status filters, language, repetition window, level action, adjustment type.
2. **Row actions behind one ⋯.** `RowActions` (data-table kit): icon + label items, destructive ones
   (cancel, retire, hide) red after a divider, inapplicable ones left out, Radix keyboard (Enter /
   Space / ↓ open, arrows, Escape back to the ⋯), `dir`-mirrored, named "Actions for <row>". A chosen
   item runs after focus returns to the ⋯, and `DialogContent` now returns focus to whatever opened it
   (Radix only did so for a `DialogTrigger`). `rowActionsColumn` gives the narrow end column; the new
   card slot `menu` puts the ⋯ in the phone card's top end corner.
   Applied: penalties list + profile tab (Approve pending only, Cancel), payroll runs list (Open run),
   run lines (Adjust while draft; Payslip once approved), employee payroll tab (Payslip once approved,
   Open run), settings stages / departments / job titles (Rename, Hide ↔ Show), penalty catalogue
   groups and violations (Rename/Edit, Retire ↔ Restore). Employee card grid unchanged.
3. **Add badge** (owner's pick, add-icons option 2): `AddIcon` is a bold plus in a 24 px rounded badge,
   a light wash on primary buttons (`data-variant` on `Button`), primary-soft elsewhere. Every add
   button changes with it; Create run now uses it too.
