# T1: Monorepo scaffold, schema and shared package

Branch `feature/t1-scaffold` (from `b532c32`). Class: infra · surface. Date: 2026-11-17.

## What landed

- **Workspace:** pnpm 10 workspaces + turbo. `apps/api` (NestJS 11, Prisma 6), `apps/web`
  (Next.js 16 App Router, React 19, Tailwind 4, shadcn `components.json`), `packages/shared`
  (`@school-erp/shared`, plain TS built to CommonJS `dist/`, locales exported as `./locales/*`).
- **api house setup:** `ResponseInterceptor` envelope, `AllExceptionsFilter` (every failure carries a
  stable `error` code from `ErrorCode`; built-in Nest errors are mapped by status), global
  `JwtAuthGuard` + `@Public()`, a **placeholder `jwt` strategy in `core/auth` that rejects every
  request** (T2 replaces it), `ValidationPipe({ whitelist, forbidNonWhitelisted, transform })`,
  `ConfigModule` global with class-validator env validation (boot fails on a bad or missing
  `DATABASE_URL`), `src/config`, `src/database/DatabaseService`, `common/repositories/base.repository.ts`,
  `common/errors/coded.exception.ts`, `GET /health` → `{ status: 'ok' }` in the envelope.
  `src/app.setup.ts` holds the pipe/CORS setup so `main.ts` and the e2e harness share it.
- **Skeletons (empty, registered):** `core/{auth,users,settings,school-structure}` (each with
  `index.ts`) under `CoreModule`; `modules/hr/` with `HrModule` + `index.ts` and empty
  `employees, lists, penalties, staff-attendance, payroll, settings, domain, month-lock`.
- **Schema** (`apps/api/prisma/schema.prisma`, `// ── core ──` / `// ── hr ──`): User, RefreshToken,
  Counter, SchoolSetting, SettingChange, Stage · Department, JobTitle, Employee, PenaltyGroup,
  Violation, ViolationLevel, PenaltyRecord, LatenessEntry, PayrollRun, PayrollLine (incl. department
  snapshot `departmentId` / `departmentNameEn` / `departmentNameAr`, indexed), PayrollAdjustment.
  UUID ids, snake_case mapping, money `Int` piastres, days `Decimal(5,2)`, every FK and filtered
  column indexed. One migration `20261117001808_init`, plus CHECK constraints (levels 1–5, days > 0,
  minutes 0–6000, month format, salary and adjustment amount > 0).
- **shared:** enums (WorkSystem, Gender, EmployeeStatus, PenaltyAction, PenaltyStatus, PayrollStatus,
  AdjustmentType, RepetitionWindow, PayrollFlag, plus Language, Weekday, SettingScope, UserRole) as
  `const` objects + union types + value arrays; setting keys, value types, §7 defaults and limits;
  `ErrorCode`; event names + payloads; request/response types for every contract route;
  `rules/index.ts` (empty); `locales/{en,ar}/common.json` (identical keys; a test enforces parity and
  that every error code and enum value has a label).
- **web:** `src/lib/{api.ts,handleResponse.ts,callApi.ts,middlewareFunctions.ts,types.ts}` (typed
  port of the house fetch wrapper; no global `src/apis.ts`), `src/store/userStore.ts`,
  `src/shared/lib/{utils.ts,i18n.ts}`, folders `src/core`, `src/shared/{components/ui,components/layout,
  lib,hooks}`, `src/modules/hr`, `src/app/[locale]/` (root layout sets `lang`/`dir`; placeholder page).
  Light tokens only in `globals.css` (neutral shadcn values; T3 swaps in Campus).
- **Infra:** root `docker-compose.yml` (Postgres 16, `school-erp-db`, host 5442, volume
  `school-erp-pgdata`), `.env.example` per app, db scripts inline `DATABASE_URL`,
  `prisma.config.ts` (seed `prisma/seed/index.ts`, empty), `scripts/e2e-db.sh <n>`,
  `.github/workflows/ci.yml`, `.gitignore` additions.
- **Lint / module rules:** house ESLint configs for api and web, with boundaries pointed at
  `src/modules/` and `src/core/` (front door `index.ts` only, core ↛ modules, common ↛ core/modules;
  web core/shared ↛ modules); `packages/shared` lint bans framework imports. Root
  `.dependency-cruiser.cjs` (no cycles, same direction and front-door rules, shared imports no framework).
  Every rule was checked against a deliberate violation, then the violation removed.

## Decisions the plan didn't make

- **Pagination cap is 100** (contract) in `BaseRepository`, not the skill's 20.
- **Error codes:** the filter always fills `error` with a stable code (`VALIDATION_FAILED`,
  `NOT_FOUND`, …) instead of Nest's human labels; `CodedException(status, ErrorCode.X)` for business
  codes. Message translation stays with T2.
- **Employee code:** `Counter` table (`name = 'employee_code'`) incremented atomically by T5, plus
  `Employee.code` unique. Codes are never reused.
- **RefreshToken table** added now (T2 needs it for rotation; avoids a schema collision).
- **Setting keys are fine-grained** (`hr.lateness.steps`, `hr.payroll.dayDivisor`, …) so history is one
  row per changed key. `SETTING_DEFAULTS` in shared holds the §7 defaults; the school name default is
  empty (seed only).
- `PayrollLine.employeeId` is a real FK (employees are never deleted); department fields are plain
  snapshot columns. `PayrollLine.flags` is `String[]` holding `PayrollFlag` values. Run totals are not
  stored (T9 sums lines).
- PenaltyRecord also has `cancelledById` / `cancelledAt` for the cancel audit.
- **Versions:** Prisma 6.19 (not 7), ESLint 9, TypeScript 5.9 (inside typescript-eslint's range),
  dependency-cruiser **16.10** (17+ refuses local Node 23; CI uses Node 22).
- dependency-cruiser runs once per app through `tsconfig.depcruise-{api,web}.json` at the root, because
  both apps use the `@/` alias for different folders.
- Root redirect `/` → `/ar` in `next.config.ts` until T2/T3 add locale middleware. `next-env.d.ts` is
  generated (`next typegen` runs in `typecheck`) and git-ignored.
- `components.json` keeps shadcn's default `iconLibrary` (lucide); T3 picks the icon set.
- Local Postgres user/password are the compose dev defaults (`postgres`/`postgres`), as in the skill's
  docker rules; no other credentials anywhere.
